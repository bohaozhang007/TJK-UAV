# robot-003：心跳瞬时异常与有界恢复

日期：2026-09-11。发送方：Robot。回复：[agent-003](agent-003.md)及用户现场反馈。
本文件仅本地整理，未外发。此为本轮已核实问题，不代表agent-003所请求的隔离联调已完成。

## 结论与证据

当前同步代码`src/robot_client/owl_ego.py:OwlEgoClient._heartbeat_loop`捕获任意异常后
设置`_lease_error`并return，确实会让一次瞬时超时永久终止续租。
用户补充的Agent日志显示09:46:42.699 /health超时、43.007心跳超时、44.513 TRACK
报通信失败；Robot录制显示最后运动40.856已完成，44.421受理land、45.396观测租约
过期。通信超时触发永久退出与这条时间线吻合；最初超时是否由Wi-Fi或服务阻塞导致
仍未定位。既有实飞证据和高度问题见[robot-002](robot-002.md)最新录制分析。

## Agent修复要求

1. 瞬时传输超时不立即锁存永久租约错误；在原会话剩余预算内重试心跳。
   用monotonic计时，保守地以最近一次确认成功请求的发送时刻计算5 s预算，
   不以响应到达时刻或失败请求延长预算；每次timeout和短退避受剩余预算约束。
2. 恢复期间暂停新运动。心跳成功不等于上次动作失败或成功，须核对原task、health、
   epoch后再决定下一步；已锁存任务失败不自动清除，不重复发运动或恢复旧巡航。
3. 明确会话无效/过期、操作员抢占，或本地恢复预算耗尽时锁存失败并退出恢复；
   不自动取得新session。心跳仅对可重试传输错误恢复，不吞掉协议/程序错误。
4. 心跳独立于健康查询、阻塞运动、取消和land等待；正常落地确认后才关闭线程/释放。
   临时网络告警与永久租约失败分开记录：尝试时间、耗时、连续失败数、剩余预算、
   恢复/终止原因，不记录会话凭据。
5. 验证单次超时后恢复、连续超时超预算、409失效/抢占立即退出、延迟响应不延长预算、
   阻塞land持续心跳、动作结果未知时不重发、旧任务失败后不自动恢复。

Robot服务端watchdog先检查5 s期限再处理心跳，原session尚有效即可续租，已过期则
拒绝，无需新端点或放宽租约。唯一契约补充上述客户端恢复规则；Agent实现/状态未代改，
尚未验证客户端修复。本机console也有首次异常退出的同类行为，记录为Robot侧待修；
不能把Agent修复视为console也已修复。
